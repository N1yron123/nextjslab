# Практическая работа по Next.js

Тема: маршрутизация, layout и template.

Сделаны страницы: главная, о нас, блог, отдельные посты и комментарии, курсы.

## Запуск

Нужен Node.js 20 или новее.

```bash
npm install
npm run dev
```

Открыть http://localhost:3000

## Проверка

- `/about` — страница «О нас»
- `/blog` — список постов
- `/blog/1` — пост с id 1
- `/blog/1/comments/5` — комментарий 5 к посту 1
- `/courses` — список курсов
- `/courses/html` — страница курса

В меню активная ссылка выделяется жирным. Есть кнопка перехода на «О нас».

В блоге использованы `layout.tsx` и `template.tsx`. При переходах между постами можно заметить, что поле ввода в template очищается. В консоли браузера тоже появляется сообщение.
